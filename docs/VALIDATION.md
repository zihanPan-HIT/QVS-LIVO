## 启动与退出

在隔离的本机 ROS domain 中启动公开 launch，通过参数服务读取并确认：

- `vio.camera_mode = four`，`vio.adaptive.enable = true`。
- 四相机线程数为 4；IMU 缓冲容量 8192，溢出终止开启。
- 额外四路点云着色、持久全局地图和 PCD 导出关闭。
- 定位节点发布 READY，相机输入整形节点运行。
- 通过 launch 发送一次停止请求后，两个子进程均正常退出。

本轮验证涵盖构建、算法单元／契约测试及无传感器启动检查，未重新执行实车或 bag 精度评估，不据此给出新的定位精度指标。
