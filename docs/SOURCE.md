# 源码来源与发布边界

发布整理日期：2026-11-08。

## 算法来源

采用实车 QVS-LIVO **adaptive3** 主线。其已归档 ROS 2 基础提交为 `4930531`（2026-09-08），随后叠加实时 S5 和 2026-10-04／2026-10-05 的部署修复。本次从 2026-10-25 保存的实车复现源码提取 `phase1_livo_core_ws/src/livo_core`，并非将基础提交误标为包含后续修复的完整版本。

后续修复涉及相机观测批次、VIO 执行、激光预处理、局部扫描接口和体素匹配。该源码与本项目另存的仿真 VIO／wheel／GPS 候选分开保存；后者未纳入本次发布。

`vikit_common` 与 `vikit_ros` 使用该实车复现环境中已有的 ROS 2 适配源码。Livox 只收录原始 `CustomPoint.msg` 和 `CustomMsg.msg`，由本仓库的最小 ROS 2 消息包生成接口。

## 发布整理

- 新增独立工作区、无界面 launch、依赖说明和实车四相机配置。
- 默认关闭持久全局地图、PCD／COLMAP 导出和额外四路点云着色，保持 adaptive3 四相机定位开启。
- 保留定位所需的局部几何地图、观测历史、原有 ROS 点云与诊断接口。
- 保留时间戳不变的 10 Hz 相机输入整形脚本。
- 移除 RViz 配置、历史 ROS 1 launch 和三个依赖外部历史实验运行目录的 Python 测试；保留核心测试。
- 清除两处本机路径注释，修正核心包的许可证元数据，补充上游许可证正文。
- 按当前 OpenMP 实现更新摘要计数与分配失败测试；工作线程故障测试显式启用四线程，队列测试补齐入口时间记录，日志及坐标系文本断言与当前实现对齐。保留篡改拒绝、状态提交与故障传播的检查。
- 将实车启动脚本中的四线程、8192 条 IMU 缓冲和溢出终止设置纳入默认配置。
- 未改写激光／IMU／视觉的状态更新与自适应选择算法。

## 未发布的内容

网页控制台、地图查看器、语义网络及权重、2.5D 地形／风险地图、导航规划、底盘控制、仿真 GPS 后端、bag、点云文件、实验报告与私有设备配置均不在发布目录中。

标定 YAML 为原传感器组合的示例；更换硬件时需要重新配置。源码中的研究用 shadow 路径保留用于现有契约测试，生产构建默认 `LIVO_BUILD_EXPERIMENTAL_SHADOWS=OFF`。
